Webex connection

The app renews its Webex token on its own every day, which keeps it from expiring. You only need this form if the keys stop working, for example after someone regenerates the client secret.

Also change the client ID or client secret

Where to find these

  1. Open your Service App in the Webex Developer Portal.
  2. For a new secret, click Regenerate the client secret and copy it.
  3. Under Org Authorizations, paste that secret into Enter Client Secret and click Generate tokens.
  4. Copy the refresh token. If you regenerated the secret, paste both here.

Saved values are encrypted to the Windows account running this app and never shown again.
